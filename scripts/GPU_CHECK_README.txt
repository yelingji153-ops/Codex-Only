ACAね 本地 GPU 环境检查

1. 将压缩包完整解压到一个文件夹，不要直接在压缩包里运行。
2. 双击 Run_GPU_Check.cmd，无需管理员权限。
3. 等待窗口显示结果，将同一文件夹中的 gpu-check-report.txt 上传回当前聊天。

本工具不安装软件，不更改系统配置，不读取音频素材。
检查内容：显卡型号、驱动版本、显存、Python、FFmpeg、相关依赖，以及已有 PyTorch 的小型 CUDA 矩阵与 FFT 运算。
缺少 Python、PyTorch 或 CUDA 检查失败都属于有效诊断信息，请直接发回报告，不必自行安装。
该检查不运行人声分离模型；检查通过后还需验证模型推理。
不要将云端 Linux 的 Python 虚拟环境复制到 Windows 使用。
若没有生成报告，请把窗口中的错误文字发回。
