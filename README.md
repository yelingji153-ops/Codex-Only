# MIXROOM · 网页混音器

在浏览器内合成伴奏和人声，独立调节音量、声像、人声时间偏移，添加混响、明亮度和动态压缩，导出 WAV。音频不上传，无需后端服务或 API 密钥。

## 运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm start
```

默认监听 `0.0.0.0:3000`。可使用 `PORT=8080 npm start` 修改端口。支持现代 Chrome、Edge、Firefox 和 Safari；可解码格式以浏览器支持为准。修改文件后刷新页面即可。

## 使用

1. 点击或拖入伴奏和人声（每轨最多 100 MB、20 分钟）。「体验示例」会在本地生成演示音频，示例旋律为合成音色，不是真实人声。
2. 调节轨道音量、声像、静音与独听。人声偏移负值会裁掉时间线零点前的内容。点击波形或拖动进度条定位，空格播放/暂停，Home 回到开头。
3. 设置人声混响空间、湿度、明亮度，按需开启主输出动态压缩。效果同时应用于试听与导出。混响为本地生成的立体声卷积脉冲响应。
4. 导出 44.1 kHz、16-bit、双声道 WAV，包含完整时间线及有效混响尾音。默认峰值保护只衰减超过 -1 dBFS 的输出，不放大安静音频。

工程在浏览器内存中，刷新将清空。大文件导出需要较多内存。压缩器是动态控制而非硬限幅；峰值保护在导出时应用。

## 验证

```sh
npm test
```

测试覆盖音轨调度、混音状态、效果时长、峰值保护与 WAV 编码。服务器仅用于本地开发。

## Windows 桌面版

构建产物为 `dist/MIXROOM-1.0.0-Windows-x64.exe`，支持 Windows 10/11 64 位。免安装，双击启动；不需要 Node.js、网络连接或浏览器。音频导出使用系统保存对话框。关闭程序后工程会清空，请先导出混音。

自行构建需要 Node.js 22 或更新版本：

```sh
npm ci
npm run desktop
npm run build:win
```

桌面版使用 Electron 内置 Chromium，所有页面资源和音频处理都在本机完成。没有自动更新、遥测或音频上传。构建依赖需要联网下载；安装包未进行商业代码签名，Windows 可能显示未知发布者提示。
