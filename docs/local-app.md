# ACAね 人声分离工作台

先完成「导入原音频 → 人声分离 → 对比试听 → 确认保留」，再开展下一阶段。
本版为双击启动的本地浏览器界面，声音文件留在电脑上，不是独立 EXE。

## 你的电脑如何启动

1. 将程序包里的 `ACAne-GPU-Setup-v2` 文件夹合并到之前的
   `D:\11bf\ACAne-GPU-Setup-v2`。更新程序文件，保留原有 `.venv-separation` 文件夹。
   不要额外套一层同名目录，也不要移动已建好的虚拟环境。
2. 双击 `Start_ACAne.cmd`，浏览器会打开工作台。使用过程中保留启动窗口。
3. 第一次点击「准备运行组件」。完整包内含分离依赖、模型和 FFmpeg，离线安装；
   复用已经验证通过的 Python 3.12、Torch 2.8.0+cu128 和 torchvision 0.23.0+cu128。
4. 选择或拖入原音频，可一次导入多份。ZIP 请先解压。勾选素材并点击「开始分离」。
5. 完成后点击「试听处理结果」，在相同位置切换原声/人声。
   选择音轨类型，写备注，满意后「确认保留」；点击「下载音轨」可另存 WAV。
6. 不满意可标记「需要重做」，回到「导入与分离」，勾选素材和「重新生成一个版本」再处理。
   同一设置重做不保证改善音质；它会保留旧版本，方便比较。

先试一首较短录音，确认本机实际推理正常和听感满意后，再导入整批。
本版固定使用已通过短片试听的 BS-RoFormer 参数，不自动训练或批准新结果。

## 保存与继续

- 原件副本、分离结果和审核记录自动保存在程序目录的 `workspace-data` 中。
- 等待当前任务完成后关闭启动窗口。重开程序仍可浏览已有素材、试听和审核。
- 正在排队或计算的任务不会跨重启自动继续；中断后重新选择素材处理。
  已成功且完整的同参数结果会复用，勾选「重新生成一个版本」则重新计算。
- 关闭程序后备份整个 `workspace-data`，才能在别的电脑恢复素材和结果。
  GitHub 只保存程序代码，音频和模型没有自动上传。
- 换电脑需另行配置 Python/GPU 环境；本包针对你已经通过 CUDA 检查的电脑，
  不包含 3.5 GB 的 Torch 安装包，也不是任意电脑通用安装器。
