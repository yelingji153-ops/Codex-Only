# 训练只读检查

将检查包解压到原 `D:\11bf\ACAne-GPU-Setup-v2`，双击 `Check_Training.cmd`。
复用现有 `.venv-training`，本机 CPU 检查，不下载、不重新训练，不改变音频、特征、模型或数据库。
唯一写入是新建 `workspace-data/diagnostics/audit_时间_编号` 报告目录。
完成后自动打开该目录，请发送 `training_audit_report.json`，不必上传模型或整个素材库。

检查内容：

- 所选片段数量、原先精确去重数量、训练快照 SHA-256；按原录音 ID 与时间范围统计重复覆盖。
- 实际 40 kHz 单声道切片的时长、电平、接近满幅比例、20 ms 低音量窗口比例；这些不是自动听感判定。
- 预处理清单/训练 filelist/磁盘 WAV 集合是否对应；所有特征和音高数组是否可读、有限、维度/长度是否合理。
- 音高标签的有声占比、范围和相邻突跳；不把音高提取器的标签当作人工核实的真实音高。
- 按固定上游实现的分桶公式核算保留切片及 batch=2、单卡时的批次数；不改采样器。
- 对现存记录校验预训练资源哈希；只从历史日志找 G/D 预训练加载消息、恢复轮次、错误及 CPU 回退。没有消息只能标未知，出现加载消息也不单独证明加载成功。
- 各轮声线导出的元数据、有限权重；续训 G/D 仅列存在和大小，不加载完整优化器状态，不把文件存在当作初始化成功证明。
- 关键训练源码与固定版本哈希比较、依赖版本。

用户已反馈同输入/同引擎的外部候选明显优于自训 30e，故优先检查训练侧；这并不证明所有弹唱素材都有问题或推理环境完全无关。

约束：不同编码的同一原录音可能拥有不同 ID，未必能识别重复；合法有限的特征仍可能标签不准或来自旧缓存。分离伪影、目标声线相似度和清晰度仍需试听对照。报告中的 review 提示不自动剔除素材，也不自动执行重训练。

检查时间取决于文件数量和磁盘速度，窗口会显示切片进度。若失败仍尽量生成报告，发报告或窗口末尾错误即可。报告包含片段编号、时间范围和技术指标；没有音频数据或模型权重，也不会自动上传。
