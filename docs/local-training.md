# ACAね 本地训练补充包（预览版）

用户已选择默认目录的全部已保存片段进行训练。本包是 v0.2 工作台的补充包，不需要重下人声分离包。

1. 将 ZIP 中的 `Start_Training.cmd` 和 `training-addon` 解压到原来 `Start_ACAne.cmd` 所在目录，通常为 `D:\11bf\ACAne-GPU-Setup-v2`。不要解压到多套一层的新文件夹。
2. 关闭正在运行的分离任务，双击 `Start_Training.cmd`，保持窗口开启。
3. 自动扫描 `workspace-data\segments` 下的所有完整批次；校验来源、当前人声审核及片段 SHA-256，跳过字节完全一致的片段。不同切分边界或不同处理版本不会自动判为同一片段；数量和时长会显示在窗口。审核记录原样保留，训练选择单独记录。
4. 首次创建 `.venv-training`，联网下载数 GB 的训练组件和预训练资源，需要连接 PyTorch、PyPI、GitHub、Hugging Face。建议预留至少 20 GB 磁盘空间，模型检查点会继续占用空间。不会改变 `.venv-separation` 或显卡驱动。本包不是离线安装包。
5. 顺序执行：CUDA 基础检查 → 工作副本 40 kHz 单声道切分（最长 3 秒、完整保留尾段；不足 0.4 秒会跳过并记入 skipped-audio.json；全静音仍报错） → RMVPE/ContentVec 特征 → 1 轮真实训练检查 → 续训到 100 轮 → 特征索引。初始 batch size 2、FP32、梯度检查点，不缓存整套数据到显存。100 轮只是首轮基线，不能保证最佳听感。
6. 只有有效声线权重和索引均通过校验才显示完成。模型在 `workspace-data\training\acane_编号\models\acane_编号`，包括 `.pth` 和 `.index`；`G_`、`D_` 文件是续训检查点。原片段不会被覆盖。

中断后重新双击：已校验的素材快照、下载缓存和训练检查点会复用；每 10 轮保存一次完整训练检查点。不要同时开两个训练窗口。新增或更改片段清单会创建新快照。若当前人声审核被撤销或素材损坏，会停止。需要重做预处理时应创建新的训练实验，不手动混用旧特征。

出现错误请保留窗口并发送同目录 `training-log.txt`，以及训练目录 `state.json`。显存不足时停止并回传日志，当前版本不会偷偷转 CPU 或自动改动训练参数。

验证范围：核心数据完整性和适配检查可在云端测试；Windows 安装、模型下载及 RTX 5070 真正训练仍须本机执行。本包发布不意味着已经训练好声线。首次资源下载通过正常 TLS，固定当时解析的 Hugging Face 仓库提交，记录下载后 SHA-256，后续按该指纹复用；首次资源哈希不是独立预审的固定信任清单。

上游代码固定 IAHispano/Applio 提交 c817f1f83f689ef72e0dfeb1c17ae990b9248506（MIT，随下载源码附 LICENSE）；所有模型和音频留在本机，不进入 Git。训练完成后仍需用固定测试歌曲转换并试听，才进入效果评估。


## v0.1.1 下载进度修正

pip 安装直接使用终端，强制开启进度条；详细日志另存 `training-pip-log.txt`，模型日志仍为 `training-log.txt`。已经运行的旧窗口不会热更新。

若当前旧窗口正在下载 torch 2.11.0，可以把新补充包解压到任意新文件夹，双击 `Show_Download_Progress.cmd`。它只读当前用户 TEMP 下对应的 pip 临时文件，每 3 秒显示大小、约略百分比、最近写入速度。总大小取截图的约 2753.2 MB，只适用于这个 Torch 安装包，不代表所有组件总进度。找不到临时文件、文件不增长或达到 100% 都不能据此判定安装成功/失败，应查看原训练窗口。此辅助窗口不修改或停止安装；PowerShell 脚本尚未在用户 Windows 上实测。

当前下载先保持运行；等其结束或报错后，再将新版补充包覆盖到原工作台目录，用新版启动器重试。不要为更新进度显示中断一个正在进行的大文件下载。


v0.1.2：过短片段不再阻断整批预处理，原件及训练输入快照保留，排除清单记录文件名、时长和原因。若跳过后不足 6 个训练切片仍停止，不能用空数据训练。失败的预处理可直接重试；已下载模型及独立训练环境复用。
