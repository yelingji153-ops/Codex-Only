## 已核实的上游代码

- 仓库：https://github.com/IAHispano/Applio
- 检查提交：c817f1f83f689ef72e0dfeb1c17ae990b9248506（上游默认分支，不等同发布标签）。
- API 返回最新发布：3.7.0，2026-10-16；其 Release 附件是更新器/更新包，不能称为完整运行时安装包。
- 仓库 LICENSE 为 MIT；预训练资源使用条件仍需分别记录。
- requirements-engine.txt 固定 torch/torchaudio 2.11.0、numpy 2.4.6、transformers 5.13.1 等。
- 与当前分离环境 torch 2.8.0+cu128 / torchvision 0.23.0+cu128 不同，不能直接把上游 requirements 安装进 .venv-separation。
- core.py 提供 preprocess、extract、train、index 入口；支持 RMVPE 和 ContentVec。
- 核对到 core.py 多处把子进程失败转换成字符串返回，CLI 仍可能正常退出。后续适配必须核对阶段产物及日志，不可仅凭父进程退出码认定训练成功。
- 训练权重下载在 rvc/lib/tools/prerequisites_download.py 中，使用 Hugging Face 的预训练生成器、判别器、音高提取器和嵌入模型；本次没有下载、安装或执行这些模型。
