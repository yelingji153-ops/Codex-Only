# 训练素材整理：切分草稿

该模块衔接已经人工确认的人声，先完成基础分析和切分。
它不训练声线，也不把建议片段自动纳入训练集。无需新增 Python 依赖或 GPU。

## 界面操作

在「对比试听」中选择已确认保留且类型为「人声」的音轨，找到「整理训练素材」。

1. 点击「分析并建议切分」。默认低音量阈值 −45 dBFS、连续低音量至少 0.3 秒，
   边缘保留 0.12 秒，建议单段不超过 12 秒。阈值和建议最长时长可在界面调整。
2. 查看平均电平、峰值、低音量窗口比例、接近满幅的采样比例。
3. 逐段试听，直接修改开始/结束秒数，或取消勾选不想保存的片段。
4. 点击「保存所选片段草稿」。保存位置显示在界面中，音轨不会被覆盖。

全静音输入不自动生成片段。短于 1 秒的片段会保留并提示，避免自动丢掉发声。
连续声音超过目标长度时会提出等长切点，并明确警告可能切断发声，需要人工调整。
本版没有歌词、音素或歌唱内容识别，不能保证切点处没有换气、长音或尾音。

片段试听播放原人声的选定时间范围；保存时才执行采样级切分。
输出为 float32 WAV，保持原采样率、声道和音量，不降噪、不归一化、不变调。
片段至少 0.05 秒，必须按时间排序且互不重叠；人工修改可以超过建议的最长时长。

## 指标含义

- 每约 20 ms 计算全部声道采样的 RMS，不先混成单声道，避免反相立体声抵消。
- RMS 低于阈值的窗口被视为低音量；气声、尾音同样可能落入其中，必须复听。
- 接近满幅指绝对采样值 ≥ 0.999。它是风险提示，不是已证实的削波检测。
- 不评估伴奏残留、噪声、混响、音色还原或训练价值，不输出 A–D 自动等级。

## 文件与恢复

`workspace-data/segments/<方案编号>.json` 保存分析指标、阈值和自动建议。
`workspace-data/segments/<批次编号>/` 保存所选片段和 `manifest.json`。
清单包含原件指纹、来源、人声模型参数、人声审核快照、切分时间和片段指纹。
短片预览会加上原录音起点偏移，保留真实来源时间。片段状态一律为 `pending`。

分析方案与已生成片段持久化；未保存的界面边界修改仅存在于当前页面。
旧方案可通过命令行恢复生成。当前界面不提供历史方案选择或逐片段最终审核，
后续将补上复核与训练数据集版本管理；现有整段人声导出不会自动包含这些片段。
人声审核变化、原件或人声哈希变化会阻止旧方案继续生成。

```sh
python -m acane --library workspace-data segment-plan --job <任务编号> --output <人声相对路径>
python -m acane --library workspace-data segment-render --plan <方案编号>
python -m acane --library workspace-data segment-render --plan <方案编号> --intervals intervals.json
```

自定义 `intervals.json` 示例：

```json
[{"start_s": 0.25, "end_s": 8.5}, {"start_s": 9.0, "end_s": 17.2}]
```

## 验证范围

已用合成音频检验静音区间、RMS/峰值、接近满幅、反相双声道、样本级切分、
来源时间、审批撤销、文件篡改及失败清理；浏览器检验分析、调整、试听、保存。
真实歌声的切分边界与 Windows 操作仍待用户验收，不等于训练素材质量已通过。
